## 全局约束

- Java 25 / Spring Boot 4.1.1，金额字符串，租户授权及下载审计保持。
- `innodb_flush_log_at_trx_commit=1`、`sync_binlog=1`；已确认事实不可丢失。
- nonce 独立持久化、渠道原始回执先于结果、未知结果查证、租约 fencing 均保留。
- 不清除现有业务数据，不自动购买资源或推送仓库；密钥不写入公共证据。
- R1 300 完成 TPS、2000 查询 QPS、D1、混合/长稳及真实远程 CI 不因本机限制改为已通过。

## 复核重点

- S3 故障或丢失对象不退回空文件；过期/跨租户下载仍拒绝；流式读写有界。
- SDK 签名与真正发送的路径、查询和原始 JSON 完全一致；重试使用新 nonce 和原业务号。
- 多凭据查询不越租户；标准渠道失败不算系统错误或成功支付。
- 数据生成可断点恢复且账务平衡；不能拼接任意分录凑规模。
- 验收进程中止、扫描/网络缺失、样本不足均不能得到通过；完整报告说明环境与覆盖。
