审查期间修复了两类任务调度边界：总并发为 1/2 时，空轮询不能推进游标而让其他队列持续失去机会；定时业务指标必须使用后台数据库角色，避免 API 池耗尽后占住共享定时调度线程。连接隔离还要求后台至少 3 个连接，为两个 BULK 流和检查点保留进展条件。对应回归先复现原问题，再验证修复。最终只读复查未发现剩余确定问题。
